# ネイロフォール（NEIRO FALL）― 5鍵の音楽会

ブラウザーで遊べる音ゲーです。上から降ってくるバーが下の線に重なった瞬間に、**Z X C V B** キーを押すか、レーンをタップします。
うまく叩くと、その音が本物の楽器の音で鳴ります。ゲージが0になるとゲームオーバー。

- 名曲20曲（著作権の切れた作品を、このゲームのために編曲）
- かんたん／ふつう／むずかしい
- PC（キーボード）・スマホ（縦持ち・横持ちのタップ）対応、ログイン不要

遊ぶ：https://ryu4649ww.github.io/neirofall/
